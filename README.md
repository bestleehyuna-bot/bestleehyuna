# 노인일자리 활동일지 스마트 관리 도구 🌿

> **화성남부노인복지관 노인일자리 참여 어르신 활동일지 디지털 관리 시스템**  
> 폴더 내의 마크다운(`.md`) 파일 및 **수파베이스(Supabase) 클라우드 DB**를 기반으로 어르신들의 일일 활동일지를 손쉽게 작성, 확인, 수정 및 엑셀로 관리할 수 있는 가볍고 강력한 웹 도구입니다.

---

## 📌 프로젝트 소개

기존의 번거로운 종이 활동일지 작성 및 수합 방식을 디지털 방식으로 전환하여, **어르신은 스마트폰으로 큰 글씨와 쉬운 터치로 일지를 작성**하고, **담당자는 수파베이스 클라우드 DB 및 로컬 마크다운 파일을 통해 실시간 일괄 확인 및 엑셀 다운로드**를 수행할 수 있도록 개발되었습니다.

별도의 복잡한 백엔드 서버 설치 없이, 순수 웹 표준 기술(HTML5/CSS3/JS)과 **Supabase 클라우드 데이터베이스**를 연동하여 **PC 및 모바일 어디서나 실시간 동기화**가 가능합니다.

---

## 🌟 핵심 기능

### 1. ⚡ 수파베이스(Supabase) 클라우드 DB 실시간 연동
- **원클릭 설정 팝업**: 화면 상단의 **[수파베이스 설정]** 버튼을 통해 Supabase Project URL과 Anon API Key만 입력하면 즉시 클라우드 모드로 전환됩니다.
- **실시간 데이터 동기화 (Realtime)**: 어르신이 휴대폰으로 일지를 제출하거나 담당자가 상태를 변경하면 새로고침 없이 즉시 모든 기기에 실시간 반영됩니다.
- **로컬 & 클라우드 하이브리드 지원**: Supabase 연동 전에도 로컬 브라우저와 파일 시스템(`.md`)을 통해 완벽하게 정상 동작합니다.
- **원클릭 테이블 생성 스크립트**: 제공된 [`supabase_schema.sql`](supabase_schema.sql) 파일을 Supabase SQL Editor에 붙여넣기만 하면 테이블 및 RLS 정책이 자동 구성됩니다.

### 2. 📁 로컬 폴더 및 마크다운(`.md`) 파일 연동
- **내 폴더 열기 (File System Access API)**: 브라우저에서 `활동일지_데이터` 폴더를 선택하면 내부의 모든 `.md` 파일을 즉시 파싱하여 화면 및 클라우드에 표시합니다.
- **실시간 수정 및 마크다운 파일 생성**: 담당자가 내용을 수정하거나 어르신이 새로 제출하면 즉시 표준 YAML Frontmatter 형식의 `.md` 파일로 변환되어 저장/다운로드됩니다.
- **기본 샘플 데이터 탑재**: 폴더나 DB를 열지 않아도 바로 기능을 테스트해볼 수 있는 샘플 일지 데이터가 기본 포함되어 있습니다.

### 3. 👵 👴 어르신 전용 모바일 간편 작성 모드
- **초대형 글씨 & 큼직한 UI**: 시력이 약하시거나 스마트폰 조작이 서투신 어르신을 위한 시니어 맞춤형 UX (20px~34px 크기의 큰 글씨와 둥근 버튼)
- **간편한 원터치 본인 선택**: 복잡한 로그인이나 비밀번호 없이 **사업단 선택 → 본인 성함 터치**로 작성 시작
- **선택형 활동 체크리스트**: 직접 긴 글을 입력할 필요 없이 오늘 진행한 활동 항목을 터치하여 간편 체크
- **건강 상태 및 메모**: 이모지와 큰 버튼으로 오늘의 건강 상태 선택 및 전달사항 입력
- **제출 축하 효과**: 작성 완료 시 기분 좋은 축하 애니메이션(컨페티)과 함께 담당자 확인 대기 상태로 접수

### 4. 👩‍💼 👨‍💼 담당자 통합 관리 대시보드
- **실시간 3단계 KPI 현황판**:
  - 📄 **전체 활동일지**
  - ⏳ **확인 대기 중** (노란색 강조)
  - ✅ **확인 완료** (초록색 강조)
- **원클릭 확인 토글**: 일지 목록에서 클릭 한 번으로 `담당자 확인 중` ↔ `확인 완료` 상태 변경
- **일괄 확인 완료**: 대기 중인 모든 활동일지 또는 선택한 항목들을 한 번에 승인 처리
- **다차원 필터링 & 빠른 검색**:
  - 사업 구분: 공익활동형 / 역량활동형
  - 사업단별: 공원환경관리, 학교급식, 노노케어, 보육시설지원, 공공시설관리, 노인시설지원 등
  - 상태별: 전체 / 담당자 확인 중 / 확인 완료
  - 날짜 필터 및 참여자 성함 실시간 검색
- **상세 편집 & 마크다운 원본 뷰어**: 활동시간, 항목, 메모 등을 담당자가 직접 수정하고 원본 `.md` 코드를 열람 및 다운로드
- **📊 엑셀(Excel `.xlsx`) 다운로드**: 필터링된 전체 활동일지를 정돈된 엑셀 집계표 형태로 원클릭 내보내기

## ⚡ 수파베이스(Supabase) 연동 3단계 가이드

1. **테이블 생성 (1회만 진행)**:
   - [Supabase 대시보드](https://supabase.com)에 로그인 후 프로젝트를 생성합니다.
   - 좌측 메뉴 **SQL Editor** ➔ **New query**를 클릭합니다.
   - 프로젝트 내의 [`supabase_schema.sql`](supabase_schema.sql) 파일 내용을 복사하여 붙여넣고 **[Run]**을 실행합니다.

2. **API 정보 확인**:
   - Supabase 좌측 하단 **Project Settings** ➔ **API** 메뉴로 이동합니다.
   - **Project URL**과 **Project API Keys (anon public)** 값을 확인합니다.

3. **웹 화면에서 연동**:
   - 상단의 **[수파베이스 설정]** 버튼을 누르고 URL과 Anon Key를 입력한 뒤 **[연결 테스트 및 저장]**을 누르면 완료됩니다!

## 🚀 빠른 시작 및 실행 방법

### 방법 1. 원클릭 실행 (가장 추천)
폴더 내의 **`실행하기.bat`** 파일을 더블 클릭하면 기본 브라우저(Chrome / Edge / Whale 등)에서 즉시 실행됩니다.

### 방법 2. 웹브라우저로 열기
**`index.html`** 파일을 브라우저 창으로 드래그하거나 더블 클릭하여 실행합니다.

## 📂 마크다운(MD) 파일 규격

각 활동일지는 **YAML Frontmatter**와 **Markdown 본문**으로 구성되어 있어 사람이 읽기 쉽고 다른 시스템과의 연동도 용이합니다:

```markdown
---
id: 2026-09-29-공원환경관리-김영희
date: 2026-09-29
program_type: 공익활동형
group_name: 공원환경관리
name: 김영희
status: 확인 완료
hours: 3
time_range: 09:00 ~ 12:00
activity_items:
  - 산책로 쓰레기 수거 및 분리수거
  - 벤치 및 공용 운동기구 주변 환경 정비
health_condition: 양호
note: 가을 낙엽이 많아 산책로 위주로 집중 청소함.
reviewer: 담당자(이수진)
reviewed_at: 2026-09-29 13:30
---

# 노인일자리 활동일지

- **일자**: 2026-09-29
- **사업구분**: 공익활동형 > 공원환경관리
- **참여자**: 김영희
- **활동시간**: 09:00 ~ 12:00 (3시간)
- **주요 활동**:
  - [x] 산책로 쓰레기 수거 및 분리수거
  - [x] 벤치 및 공용 운동기구 주변 환경 정비
- **건강상태**: 양호
- **특이사항**: 가을 낙엽이 많아 산책로 위주로 집중 청소함.
- **담당자 확인**: 확인 완료 (이수진, 13:30)
```
