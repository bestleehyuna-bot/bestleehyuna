# 노인일자리 활동일지 스마트 관리 도구 🌿

폴더 안에 있는 마크다운(`.md`) 파일 기반으로 노인일자리 참여 어르신들의 일일 활동일지를 직관적으로 확인·체크·관리할 수 있는 스마트 도구입니다.

---

## 🌟 주요 특징

### 1. 📁 폴더 내 MD 파일 자동 연동 & 파싱
- **내 폴더 열기**: 작업 폴더(`활동일지_데이터`)를 선택하면 폴더 내 모든 `.md` 활동일지를 즉시 읽어와 대시보드에 표출합니다.
- **실시간 체크 & 수정**: 담당자가 화면에서 수정한 내용 및 확인 상태가 즉시 반영되며 마크다운 파일로 다운로드/저장 가능합니다.
- **기본 샘플 데이터 내장**: 별도 폴더 선택 없이도 즉시 테스트해볼 수 있는 기본 활동일지가 탑재되어 있습니다.

### 2. 👵 👴 어르신 전용 모바일 작성 모드
- **초대형 글씨와 버튼**: 시력이 약하신 어르신도 손쉽게 사용할 수 있도록 큼직한 폰트와 터치 버튼 적용
- **쉬운 본인 선택**: 복잡한 로그인 없이 사업단과 성함 터치 한 번으로 선택
- **원터치 체크리스트**: 활동 항목(환경정비, 급식소독, 안부확인 등)을 터치하여 간편하게 일지 작성
- **제출 축하 효과**: 제출 완료 시 재미있는 컨페티 효과와 함께 즉시 접수 처리

### 3. 👩‍💼 👨‍💼 담당자 관리 & 검토 대시보드
- **실시간 통계 현황판**: 전체 일지 수, 확인 대기 중, 확인 완료 건수, 오늘 활동자 수 요약
- **다차원 필터 및 검색**:
  - 사업구분 (공익활동형 / 역량활동형)
  - 사업단별 (공원환경관리, 학교급식, 노노케어, 보육시설지원, 공공시설관리, 노인시설지원 등)
  - 확인 상태별 (담당자 확인 중 / 확인 완료)
  - 날짜별 및 참여자 성함 검색
- **원클릭 일괄 확인**: 대기 중인 여러 일지를 한 번에 `확인 완료` 상태로 일괄 승인
- **상세 편집 & MD 원본 보기**: 어르신이 작성한 시간, 메모, 활동내용을 담당자가 자유롭게 수정
- **엑셀(Excel .xlsx) 다운로드**: 필터링된 일지 데이터를 원클릭으로 엑셀 집계표로 내보내기

---

## 🚀 실행 방법

### 방법 1: 원클릭 실행 (가장 간단함)
- 폴더 안의 `실행하기.bat` 파일을 더블 클릭하면 브라우저(Chrome / Edge 등)에서 바로 열립니다.

### 방법 2: 웹브라우저에서 직접 열기
- `index.html` 파일을 더블 클릭하거나 브라우저 창으로 드래그하여 실행합니다.

## 📂 마크다운(MD) 파일 구조 규격

각 어르신의 활동일지는 다음과 같은 구조(YAML Frontmatter + Markdown)로 자동 생성 및 관리됩니다:

```markdown
---
id: 2026-09-29-공원환경관리-김영희
date: 2026-09-29
program_type: 공익활동형
group_name: 공원환경관리
name: 김영희
status: 확인 완료
hours: 3
time_range: 09:00 ~ 12:00
activity_items:
  - 산책로 쓰레기 수거 및 분리수거
  - 벤치 및 공용 운동기구 주변 환경 정비
health_condition: 양호
note: 가을 낙엽이 많아 산책로 위주로 집중 청소함.
reviewer: 담당자(이수진)
reviewed_at: 2026-09-29 13:30
---

# 노인일자리 활동일지

- **일자**: 2026-09-29
- **사업구분**: 공익활동형 > 공원환경관리
- **참여자**: 김영희
- **활동시간**: 09:00 ~ 12:00 (3시간)
- **주요 활동**:
  - [x] 산책로 쓰레기 수거 및 분리수거
  - [x] 벤치 및 공용 운동기구 주변 환경 정비
- **건강상태**: 양호
- **특이사항**: 가을 낙엽이 많아 산책로 위주로 집중 청소함.
- **담당자 확인**: 확인 완료 (이수진, 13:30)
```
